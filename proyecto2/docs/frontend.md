# Backend REST Service with Express and Mongoose

Este proyecto es un servicio fronted para interactuar con el backend de la base de datos
## Objetivo

El objetivo de este servicio es permitir la gestión de los datos a travez de una intefaz grafica

## Requisitos y Tecnologías

- **Node.js**: 18.20.4
- **yarn**: latest-version
- **React**: Framework web para Fronted

## Instalación

1. Clona este repositorio.
2. Accede a la carpeta `proyecto2/fronted`.
3. Instala las dependencias necesarias ejecutando:

```bash
yarn install
```


## Ejecutar el servicio

1. Inicia el fronted pero despues del backend, con el siguiente comando:

```bash
npm run dev
```

2. Este comando iniciaria el proyecto de fronted ojo acceda a 
```bash
localhost:3001/
```
